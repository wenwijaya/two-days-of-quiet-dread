## Run it

```sh
MAKEFUN_OUTPUT_DIR=/tmp/out python3 main.py
```

The program writes the comment to `$MAKEFUN_OUTPUT_DIR/entry.txt`. The readable source is `entry.py`; `main.py` is the kit's compressed pack of it (`node cli/makefun.mjs compress entry.py --out main.py`).
